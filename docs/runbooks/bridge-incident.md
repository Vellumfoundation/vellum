# Bridge Incident Runbook

1. Identify affected flow: deposit, withdrawal, proof, finalization, or indexer.
2. Confirm canonical contracts and recent admin actions.
3. Check parent and L3 transaction hashes.
4. Check bridge indexer lag and stuck messages.
5. Communicate user impact and withdrawal timing clearly.
6. Escalate security review for unexpected contract behavior.
7. Publish status updates until resolved.
