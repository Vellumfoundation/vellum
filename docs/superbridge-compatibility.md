# Superbridge Compatibility

The Superbridge handoff package lives in `bridge/superbridge`.

Required files:

- `chain-metadata.json`
- `bridge-addresses.json`
- `token-list.json`
- `integration-notes.md`
- `assets/icon.svg`
- `assets/icon.png`
- `assets/logo.svg`

Before external handoff, all addresses must be real, native gas must be ETH,
parent chain must be Base, and deposit/withdrawal tests must be linked.
