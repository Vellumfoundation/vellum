# Bridge

The bridge target is standard OP Stack canonical bridging.

Supported flows:

- ETH deposit from Base to Vellum.
- ETH withdrawal from Vellum to Base.
- ERC-20 deposit through standard bridge mappings.
- ERC-20 withdrawal through standard bridge mappings.

Production bridge docs must include contract addresses, ABIs, proof/finalization
steps, challenge period, token mappings, and test transaction links.
