# Testnet Launch Checklist

## Current Gate

Run the readiness report at any time:

```bash
pnpm testnet:readiness:report
```

Re-run the chain ID registry check before any public announcement:

```bash
pnpm testnet:chain-id
```

The launch-blocking gate is intentionally strict:

```bash
TESTNET_READINESS_REQUIRE_SECRETS=1 pnpm testnet:readiness
PROJECT_ENV=testnet pnpm validate:config
```

Both commands must pass before a public Base Sepolia testnet is announced.
