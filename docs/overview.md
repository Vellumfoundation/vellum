# Overview

Vellum is a Base-settled Ethereum-compatible L3 rollup using ETH as native
gas. The target stack is OP Stack or an OP Stack-derived deployment that keeps
standard bridge semantics and normal EVM developer ergonomics.

Users should be able to add the chain to a wallet, bridge ETH from Base, send
ETH on the L3, deploy contracts, use an explorer, and withdraw through the
canonical path.

The current repository phase is foundation scaffolding. No production launch is
allowed until validation, tests, audits, monitoring, bridge flows, and runbooks
are complete.
