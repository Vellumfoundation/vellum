# Superbridge Integration Package

This package is the handoff surface for Superbridge or any Superbridge-compatible
canonical bridge frontend.

It includes:

- `chain-metadata.json`
- `bridge-addresses.json`
- `token-list.json`
- `integration-notes.md`
- `assets/icon.svg`
- `assets/icon.png`
- `assets/logo.svg`
- `validation/`

Production release is blocked until all bridge addresses are real, all URLs are
live, native gas is ETH, parent chain is Base, and deposit/withdrawal test
transactions are linked in `integration-notes.md`.
